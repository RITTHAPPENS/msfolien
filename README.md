# MS-Folientechnik Website

Statischer Prototyp (HTML/CSS/JS) für ms-folientechnik-eifel.de, Vorlage für die Umsetzung in WordPress/Elementor.

- `index.html` Startseite
- `assets/` CSS, JS, Bilder (WebP), Schrift (Archivo, selbst gehostet), Icon-Sprite (Phosphor)

Lokal ansehen: `python3 -m http.server` im Ordner starten.
